# Subgroup Analysis: Fluvir™ Treatment Effects by Gender and Comorbidity

This project investigates whether the treatment effect of Fluvir™ differs across patient subgroups, specifically by gender and comorbidity status.

## Overview
Subgroup-specific logistic regressions and interaction models were used to assess differential treatment responses. Forest plots were created to visually present odds ratios.

## Methods
- Stratified logistic regression models for male and female groups.
- Formal interaction test (Treatment × Gender).
- Subgroup analysis by comorbidity status.

## Tools
- **R Programming Language**
- **tidyverse**, **broom**

## Key Findings
- Fluvir™ improves recovery in all subgroups.
- The effect is more pronounced in patients without comorbidities.
- Gender did not significantly modify the treatment effect.
